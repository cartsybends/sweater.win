    How these projections work

    Points per game = (goals + assists) ÷ games played. Full-season pace multiplies that unrounded rate by the selected season length, even when a player has already missed games.

    The scenario finish starts with recorded points, then adds the adjusted scoring rate for the remaining games you choose to play. Player mode uses the current club’s games played to account for the team’s remaining schedule; Calculator mode uses the games you entered. Totals across traded clubs are combined. Unknown current clubs use the player’s games played as a manual starting assumption.

    These are pace estimates, not a prediction model. Early-season samples, role changes and future availability can change the result. Goal and assist estimates are rounded separately. Player stats refresh with the site’s NHL data build; the snapshot date appears with each selection.
