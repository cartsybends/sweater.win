# Trophy Case photos

These ten unmodified photographs come from the official [NHL Records trophy directory](https://records.nhl.com/awards/trophies). NHL Records is credited in Trophy Case's game help.

`images.json` records each game's award name, the NHL trophy ID, original image URL, local filename, and SHA-256 checksum. The official name “Maurice ‘Rocket’ Richard Trophy” maps to the game's existing “Maurice Richard Trophy” label (NHL trophy ID 15).

The builder verifies that every Trophy Case award has one local photo and copies the images into the published `trophies/` folder. Gameplay does not depend on an external image host.
