# Trophy Case photos

These eleven unmodified photographs come from the official [NHL Records trophy directory](https://records.nhl.com/awards/trophies). Ten cover Trophy Case's awards; the Stanley Cup is used by Sweater Grid. NHL Records is credited in both games' help.

`images.json` records each game's award name, the NHL trophy ID, original image URL, local filename, and SHA-256 checksum. The official name “Maurice ‘Rocket’ Richard Trophy” maps to the game's existing “Maurice Richard Trophy” label (NHL trophy ID 15).

The builder verifies coverage and all source checksums, then copies the images into the published `trophies/` folder. Gameplay does not depend on an external image host. Grid uses Trophy Case's dark-theme screen blend so the photographs sit directly on the panel without a white tile; the original photos remain unchanged.
